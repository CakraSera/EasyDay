# Log cues, ID and EN

Indonesian and English mix freely in Logs. Pain: nyeri, sakit, pegal, perih,
ngilu, cedera, keseleo / painful, hurts, ache, injury, sprain. Effort:
hard, keras, tempo, intervals, race, balapan / lelah, capek, heavy legs.
Walking: jalan, jalan aja / walk, walked. Volume: menit, minutes, km, k.
"Rabu lutut agak nyeri, jalan aja" reads: Wednesday knee pain, walked
instead — pain gate on, honor the walk.
